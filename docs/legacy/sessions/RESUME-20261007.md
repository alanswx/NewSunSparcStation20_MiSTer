## Gotchas learned this session

- **A background `sleep N; build` starts late:** check the build's start
  time against the last source edit before trusting what it built (one
  build started 1 s after I checked and then held both batches).
- **`pgrep -f` matches its own command line** (again): a waiter that
  `pgrep`s for a script name never ends. Wait on the background task.
- **OBP 2.x at `ok`:** `show-devs` pages and its pager swallows the next
  keys; `cd` and `show-attrs` take the rest of the line as the path (no
  `.attributes` after them on the same line); there is no `dev`;
  `.attributes` is OBP 2.x's `.properties`.
- **Main's file browser:** the first typed letter jumps, the following
  ones filter (within 2 s of each other); the filter seems not to see the
  extension. `scripts/board/hotplug.sh` has working key sequences.
- **Stop-A from uinput:** Stop must still be down when A goes down
  (`+100 +59 -100 30 -59`), as on a Sun.
- **The sol8-ss20 image was installed under QEMU:** its `c0…` and
  `/dev/sound` links point at QEMU's device paths. On the SS20 the SCSI
  controller is `c1`; `devfsadm -c disk` / `devfsadm -i audiocs` make the
  right links. Solaris reads CDs in 512-byte blocks (OSD CD-ROM block size
  512). Solaris's `/bin/sh` has no `$(...)`.
- **mrext screenshots** do not show the OSD; OpenBIOS needs ~40 s to show
  its prompt on the screen after a core load.
- **The `.qsf` files now carry `MISTER_FB_PALETTE`** (committed): after a
  build, `git restore -- SunSparcStation20.qsf SunSparcStation.qpf` keeps
  them right.
