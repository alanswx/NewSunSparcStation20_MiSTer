## Background for the user

BuildDisk is the installation's second phase: the first phase already
puts a bootable base system on the disk (it runs the GUI today), and
BuildDisk adds the CD's optional packages. Until it succeeds, NeXTSTEP
starts it at every login and the installation counts as unfinished.
