## Where things stand

- **Release SunSparcStation20_20261006** (`62e149a`): the whole board
  regression passed (releases/README.md lists it); the POST stops at the
  memory controller's test as documented.
- **S2, CD audio** (`137c435` + Main `bc39fe7`): READ TOC from the disc's
  real track table, PLAY AUDIO (10/12/MSF/TRACK), PAUSE/RESUME, STOP,
  READ SUB-CHANNEL, the volume page; a 4-frame ring fetched between SCSI
  requests, 44.1 kHz, mixed with the machine's sound. Simulation
  (`sim/run-scsi.sh`'s CD run) and board (`hwtest.sh cdaudio`) pass.
- **S3, bell and click** (`dfa41e2`): `ts_beep` on top of the CS4231.
- **ESP-8** (`eb1d0bf`): MESSAGE ACCEPTED reported a disconnect even when
  the target wanted the next byte; NeXTSTEP's sync negotiation now works
  (no more "SCSA: bad pkt_reason 14"). The target also takes queue tags
  (`95bf34f`).
- **E4**: OpenBIOS formats a blank NVRAM at once (`349851e`); releases ship
  `ss20.nvr` (`tools/mknvram.py`). The 12.6 s at boot is NOT the NVRAM: a
  formatted image boots in the same 35 s to `ok`; the time is OpenBIOS's
  Forth init (PLAN E4).
- **N1**: see PLAN. NeXTSTEP boots under the Sun OBP to its GUI on the
  release build (`hwtest.sh nextstep-obp` passes).
- After the release: a **30-minute stress** on both CPUs (Sun OBP,
  Solaris) passed.
- **L2 TLB default:** the OSD option only matters when software sets MCNTL
  bit 6, which OpenBIOS does and the Sun OBP does not (MCNTL 0x01004b01
  under NeXTSTEP). So NeXTSTEP (Sun OBP only) is unaffected either way, and
  On would speed up OpenBIOS boots (Solaris −14 % boot, −28 % CPU-bound,
  measured in session 10). Recommendation: On by default; the user
  decides.

## Gotchas learned this session

- The MiSTer's /tmp is emptied by a Main swap (it reboots): copy pcdump and
  the uinput helpers back.
- Never `timeout`/kill pcdump mid-command: the debug link goes out of step
  until the core is reloaded.
- NeXTSTEP's boot loader takes any key during its 10 s countdown as "stop":
  send the network panel's Ctrl-C only once the panel shows (the release's
  screenshot helper `scratch/shot.sh`; `scratch/nstrap.sh` waits for two
  panel detections in a row).
- `hwtest.sh all` (with the OBP) runs its own list; extra test names after
  `all` run after it, repeats included.
